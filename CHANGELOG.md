# Changelog

## v1.0.0

Initial MVP release.

- Added CLI tool for analyzing and fixing common C compiler errors
- Added support for missing includes, implicit function declarations, undefined references, undeclared identifiers, syntax errors, and basic type mismatches
- Added interactive fix confirmation and dry-run support
- Added backup preservation before applying fixes
- Added re-compilation verification after applying fixes
- Added unit tests and negative case tests
- Added documentation for build, usage, and limitations
